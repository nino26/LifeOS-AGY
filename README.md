# LifeOS-AGY

**The Life Operating System — Powered by Google Antigravity CLI (`agy`) & Gemini**

Refactored from the canonical [danielmiessler/LifeOS](https://github.com/danielmiessler/LifeOS) to run natively on Antigravity CLI (`agy`) utilizing the Google AI Pro subscription with zero API key dependencies.

## Architecture

- **Harness:** Antigravity CLI (`agy`)
- **Intelligence Model:** Google AI Pro subscription models (`gemini-3.1-pro-high`, `gemini-3.8-flash-high`)
- **Thinking System:** The 7-phase Algorithm (Observe → Think → Plan → Build → Execute → Verify → Learn)
- **Central Primitive:** The ISA (Ideal State Articulation)
- **Memory Contract:** Cortex typed items (memory, idea, knowledge, proposal)
- **Execution Surface:** Modular skills library with YAML frontmatter discovery

## Getting Started

```bash
# Launch interactive LifeOS session in Antigravity CLI
./lifeos-agy.sh
```
